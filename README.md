# Pigeon Pitch

A deterministic Python entry for the [Pigeon Pitch](https://make.fun/bounty/u-donrulezz-pigeon-pitch-one-line-af06c6cf) competition on make.fun. The program writes the entry text to `entry.txt`, with no trailing newline. The readable source is `entry_source.py`; `main.py` is the official make.fun compress output of that source.

## Running

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

If `MAKEFUN_OUTPUT_DIR` is not set, the entry is written to `/output/entry.txt`.
